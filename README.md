# duo-wide

Демо: сайт на всю ширину сложенного iPhone Duo в Safari, включая область под боковой панелью браузера.

**Демо:** https://pro-verstka.github.io/duo-wide/

## Проблема

На сложенном iPhone Duo Safari держит сбоку столбец шириной 84pt: камера, время и кнопки браузера. В портрете он справа, в ландшафте (`landscape-primary`) слева. Это интерфейс браузера, а не safe-area:

- вьюпорт страницы 382px при экране 466px;
- все `env(safe-area-inset-*)` равны 0;
- `viewport-fit=cover` ничего не меняет;
- Fullscreen API нет.

Обычная вёрстка обрывается на краю панели, а под самой панелью виден только цвет фона `html`.

## Как это решено

1. **Определяем сложенный вид.** Safari всегда отдаёт в `screen` размеры внешнего экрана, 466×678, даже в разложенном виде. Зазор между шириной экрана и `clientWidth` есть только у сложенного устройства, и он равен ширине панели. Скрипт ставит на `html` атрибут `data-folded`.
2. **Растягиваем `body` под панель.** Отрицательный `margin` на ширину панели, а `body` становится скроллером (`html { overflow: hidden }`).
3. **Панель слева.** В `landscape-primary` на `html` ставится `dir="rtl"`: так браузер позволяет рисовать в отрицательную сторону по X. У `body` остаётся `dir="ltr"`, чтобы текст не перевернулся.
4. **Зум.** `minimum-scale=1` не даёт двойному тапу уменьшить страницу. После щипка прокрутка документа сбрасывается в 0, иначе верх страницы остаётся обрезанным.

## Подключение

Минимальный набор находится в `<head>` файла [`index.html`](index.html) и помечен комментариями 1/3–3/3:

1. `<meta name="viewport">` с `minimum-scale=1`;
2. `<style>` с правилами для `[data-folded]`;
3. `<script>` с `fit()` и `resetAfterZoom()`.

Ещё нужен `<body dir="ltr">`. Всё остальное в `index.html` — демо-контент: его стили и скрипт лежат в конце страницы.

Для своего контента используйте переменные:

- `--panel-width` — ширина панели (84px), задана на `[data-folded]`;
- `--bar-height` — запас под нижнюю строку адреса Safari.

Например, чтобы фон уходил под панель, а текст оставался в видимой зоне, добавьте контейнеру отступ на `--panel-width` со стороны панели. Так сделано в демо через `--gutter-start` / `--gutter-end`.

## Ограничения

- Ширина панели (84) и порог определения взяты из симулятора iPhone Duo на iOS 27.1. На реальном устройстве не проверено.
- Сторона панели определяется по `screen.orientation.type`. Это поведение подсмотрено в симуляторе, а не задокументировано.
- `position: fixed` обрезается по вьюпорту (382px): всё «плавающее» кладите внутрь `body` через `sticky` или `absolute`.
- Строка адреса Safari не сворачивается при прокрутке, потому что прокручивается `body`, а не документ.
- Щипок «сжать» при масштабе 1 открывает обзор вкладок Safari. Это жест браузера.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000` в Safari в симуляторе iPhone Duo.
